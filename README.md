# Saha Decorators website concept

Static HTML, CSS and JavaScript site for the Saha Decorators lead in the Cloudempire Web Dev Leads Dashboard (row 9). The illustrations and logo are **proposed visual concepts**, not official branding or photographs of business work. See `docs/SOURCES.md` for verified facts and limitations.

Run locally: `python -m http.server 8000` from this directory, then open `http://localhost:8000/`.
